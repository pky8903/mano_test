# 발표자 노트 — OPC 마스크 CD 진동 설명 영상

대상: 시니어 엔지니어링 매니저, 기술 의사결정자
영상: `out/opc_mask_cd_oscillation.mp4` (1920×1080, 30 fps, 약 4분 25초, 음성 없음)

## 한 문장 요약

경계 오차를 고치면 이웃의 예측도 바뀌므로, 보정을 반복하면 웨이퍼 오차는 0으로 수렴하면서도 최종 마스크 보정은 공간적으로 진동하는 모양으로 남을 수 있습니다. 진폭은 **초기 오차 분포**와 **모델의 공간 응답**이 함께 결정합니다.

## 장면별 노트

### S1 무엇이 진동하는가 (≈21 s)
- 막대는 휘지 않은 직선이고, **폭**이 바뀝니다. 폭 = nominal(예시 40 nm, 실험값 아님) + 50·u. ×50은 보정량 u에만 적용됩니다.
- 0–0.8 µm 구간은 첫 control 보정(+3.96 nm)이 커서 ×50으로 그리면 막대가 겹칩니다. 그래서 점선 nominal 윤곽만 그렸고, 실제 값은 그래프에 있습니다.
- 위 그래프는 마스크 보정, 아래 그래프는 남은 오차입니다. 진동하는 것은 **마스크 보정**이고 오차는 `max|e| < 10⁻¹² nm`입니다.
- 이 화면은 S3에서 다시 보여 줄 같은 시뮬레이션의 최종 상태(Iteration 806)입니다.

### S2 이웃 결합 (≈29 s)
- 한 control의 마스크를 +1 nm 바꾸면 자기 예측은 +0.30 nm(= a + b/N), 범위 안 이웃 18개는 각각 +0.053 nm(= b/N) 바뀝니다.
- R은 control 배열 위의 **거리**입니다. 빛이나 파동이 시간에 따라 퍼지는 것이 아닙니다.
- 첫 control은 경계에 있어 오른쪽 이웃 9개에만 영향을 줍니다. 잘린 창을 다시 정규화하지 않으므로 합은 a + b·(M+1)/N입니다.
- 하나의 control을 강조한 것은 설명을 위해서입니다. 실제 보정은 모든 control을 **동시에** 갱신합니다.

### S3 인과 반복 (≈75 s)
- 순서: ① 현재 오차 읽기 → ② Δu = η·e 미리보기 → ③ 누적 보정 u에 더하기 → ④ 바뀐 마스크로 오차 재계산 → 반복 번호 증가.
- 양(+)의 오차는 마스크를 넓히라는 뜻입니다. 첫 보정은 첫 control의 오차를 줄이지만, 이웃에는 음(−)의 오차를 만듭니다. 다음 보정이 이웃을 좁히면 그 효과로 더 안쪽에 양(+)의 오차가 생깁니다.
- 한 번 반복할 때 영향은 최대 M개 control까지 더 닿을 수 있습니다(옅은 띠). 이것은 **가능한 범위**일 뿐이며, 일정 속도로 움직이는 파동이 아닙니다.
- 축은 u ±0.6 nm, e ±0.06 nm로 고정했고 확대한 것입니다. 축을 넘는 값은 ▲와 함께 부호 있는 실제 값으로 표시합니다.
- **반복(Iteration)은 실제 공정 시간이 아닙니다.** 보정 알고리즘의 계산 단계입니다.
- 806회는 실제 수렴 판정(max|e| ≤ 10⁻¹² nm)에서 나온 값입니다. 최종 잔차는 9.96×10⁻¹³ nm입니다.

### S4 두 가지 감쇠 (≈28 s)
- 왼쪽(가로축 Iteration n, 로그 세로축)은 반복할수록 남은 오차가 줄어드는 **수렴**입니다.
- 오른쪽(가로축 Distance from left edge)은 경계에서 멀어질수록 최종 보정의 진폭이 줄어드는 **공간 감쇠**입니다. 표시한 봉우리 값(+0.50, +0.24, +0.12, …)은 실제 계산 배열에서 읽은 값입니다.
- S3의 확대 축(±0.6 nm)에서 전체 범위(−1~4.5 nm)로 배율이 바뀐다는 점을 화면에 명시했습니다.
- 이 예의 주기는 1.07 µm, 감쇠 길이(1/γ)는 1.45 µm입니다. 둘 다 특성근 예측값이며, 수치 꼬리 측정과 2×10⁻⁶ 이내로 일치합니다.

### S5 편차 비교 (≈31 s)
- 오차 모양은 그대로 두고 크기만 0.5 / 1 / 2 nm로 바꿨습니다. 보정 전체가 정확히 같은 배율로 바뀌고, 주기와 감쇠는 그대로입니다.
- 변동 = max(u) − min(u)이며, 측정 구간은 0.8–8.0 µm로 모든 비교에서 고정입니다.
- 배경 오차가 있으면 균일한 배경 오차만으로도 경계 근처 보정이 평탄하지 않습니다. 그래서 (배경+편차)에서 (배경만)을 **별도로 풀어** 뺀 추가 보정을 비교합니다. 이 추가 보정은 배경이 없는 예와 같습니다.
- 오차의 **모양**(전이 폭)을 바꾸는 것은 다른 실험이며, 이 배율 관계를 그대로 적용하지 않습니다.

### S6 무엇을 바꾸고 무엇을 고정했나 (≈41 s)
- **범위 비교:** M = 13 → 18 → 24이고, a = 0.25, b = 1(이웃 전체 감도 합), d, 경계 오차는 고정입니다. 이웃 하나당 가중치 b/(2M+1)은 줄어듭니다.
  - 주기: 1.52 → 2.08 → 2.75 µm
  - 감쇠 길이: 2.02 → 2.75 → 3.63 µm
  - 0.8–8 µm 변동: 0.74 → 0.54 → 0.40 nm
- **감쇠 비교:** a = 0.25 → 0.30 → 0.40이고, b = 1, M = 9, d, 경계 오차는 고정입니다. 진폭과 감쇠가 **함께** 바뀝니다.
  - 감쇠 길이: 1.45 → 0.91 → 0.62 µm
  - 변동: 0.91 → 0.47 → 0.20 nm
- 각 경우는 따로 푼 결과입니다. 전환 애니메이션 중간 프레임은 물리적인 중간 해가 아닙니다.
- 축은 ±0.6 nm 고정이며 정규화하지 않았습니다. 점선 포락선은 지배 모드 근사이며, 5% 이내로 맞는 거리부터만 그렸습니다(경계 근처는 여러 모드가 겹치므로 제외).
- **큰 범위 근사(참고):** c = a/b = 0.25로 고정하고 M이 크면 L ≈ 1.405·R_c, γ ≈ 0.543/R_c입니다(R_c = (2M+1)d/2). M = 24에서 정확한 이산 값은 L = 1.4047·R_c, γ = 0.5403/R_c입니다. 이 근사는 유한 stencil 임계점 근처에서는 성립하지 않습니다(부록 A).

### S7 보고된 관측 (≈22 s)
- EP-only calibration(CD gauge T/L/TL/TR/R/B/BL/BR/C 제외)은 CD 예측이 나빠졌고 target layout 초기 오차 분포가 개선됐으며, 보고된 막대 폭 진동이 줄었습니다.
- 이후 CD와 왼쪽 블록 경계 EP gauge를 함께 맞춘 CNN 계열 모델에서는 진동이 다시 나타났습니다. 이 모델의 target 초기 오차 분포는 아직 받지 못했습니다.
- **보고된 수치(0.5 nm 미만, 약 2 nm)는 화면에 넣지 않았습니다.** 두 값의 진폭 정의와 측정 구간이 같은지 확인되지 않았기 때문입니다. 확인되면 원래 정의 그대로 추가할 수 있습니다. peak-to-peak로 부르거나 감소 배율을 계산하지 마십시오.
- 두 비교는 오차 분포와 모델 응답을 **함께** 바꿨을 수 있으므로, 이 비교만으로 원인을 특정할 수 없습니다.

### S8 다음 단계 (≈19 s, 마지막 화면 10.5 s 유지)
1. Target layout의 초기 오차 분포를 확인합니다.
2. CD·EP fitting 정확도를 유지하며 공간 응답 조건을 개선합니다.
3. 필요하면 correction에 평탄성 조건을 추가하고 EPE 영향을 평가합니다.

보충 발언:
- 국소/비국소 균형과 영향 범위는 진단 방향으로 유용합니다. 하지만 모든 생산 모델에서 독립적으로 조정할 수 있는 물리적 손잡이는 아닙니다.
- 보정 방정식의 정확한 해가 유일하다면, solver만 바꿔서는 다른 평탄한 정확해가 생기지 않습니다. 평탄성을 원하면 그 조건을 명시적으로 넣고 EPE 손실을 평가해야 합니다.

## 모델과 알고리즘에 대한 주의

- 모델: `A = aI + b·W_M`입니다. W_M은 중심을 포함한 (2M+1)점 평균이고, 블록 밖은 0입니다. 재정규화와 주기적 연결은 하지 않습니다. d = 80 nm는 toy 가정입니다.
- 부호: `e = E − A u`, `u ← u + η e`, η = 1/(a+b)입니다. 이론 원고(`e_old = E_old δ + A u`, `u ← u − η e_old`)와는 `e_old = −e`, `E_old = −E`로 같은 u를 기술합니다.
- P형 보정은 설명용 알고리즘입니다. 생산 OPC solver나 CG가 아니며, 제곱 오차의 경사하강도 아닙니다(경사하강이라면 Aᵀ가 들어갑니다).
- 수렴한 예측 오차가 0이라고 해서 웨이퍼 정확도가 증명되거나 구현 오류가 배제되는 것은 아닙니다.

## 해서는 안 되는 주장 (PRD §4)

- 모든 경계 오차가 눈에 보이는 장주기 진동을 만든다.
- 정확한 모델은 반드시 진동하는 마스크를 요구한다, 또는 진동하는 마스크는 정확한 모델을 뜻한다.
- 반복 횟수를 늘리면 진동 진폭이 단조 증가한다.
- 범위(ambit)가 넓으면 모든 경우에 감쇠가 약해진다 → 부록 A의 반례.
- fitting 계수가 크면 유효 a나 b가 크다.
- calibration RMS가 좋아지면 target layout 초기 오차도 좋아진다.
- 800 nm 항 제거가 일반적인 해법이다.
- 임의로 평탄한 마스크가 같은 보정 방정식을 만족할 수 있다.

## 부록 A — 임계점 근처의 비단조 감쇠 (본편 제외)

- c = a/b = 0.22에서는 M = 9 → 12일 때 감쇠가 **강해집니다**(γ 0.1072 → 0.1208 /µm). 범위가 커졌는데도 그렇습니다.
- 지배근 분기에서 두 감쇠 계수는 c ≈ 0.22046339에서 교차합니다. M = 9 bulk 안정 한계 c_9 ≈ 0.21927과 이 교차점 사이에서만 M = 12 쪽 감쇠가 더 강합니다. c = 0.25(본편 기준)에서는 γ 0.6903 → 0.5325로 약해집니다.
- 이유: M이 커지면 임계값 c_N이 연속 극한 쪽으로 내려갑니다. 임계점 근처에서는 √(c − c_N) 인자가 크게 늘고 1/R_c는 줄어들어, 두 효과가 경쟁합니다.
- 이 영역에서는 가장 작은 응답 고유값이 작아서 η = 1/(a+b)의 P 반복이 매우 느리게 수렴합니다. 그래서 경영진용 본편에서는 제외했습니다.
- 수치: `data/counter_9.json`, `data/counter_12.json`. 직접해 기준이며, 원고 기준값 A₀ = 1.35087026 E, γ = 0.10720785 /µm, L = 1.06184467 µm를 8자리까지 재현합니다.
